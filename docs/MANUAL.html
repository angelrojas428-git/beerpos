Manual Profesional — BeerPOS

Sistema integral de gestión para bares y licorerías.

1. Introducción

BeerPOS es una plataforma web/PWA diseñada para la gestión operativa de bares y licorerías. Integra clientes con código QR, control de inventario, ventas, créditos (fiado), caja, reportes y panel administrativo en una sola solución.

Objetivos del sistema

  • Automatizar el registro y canje de cervezas mediante QR.
  • Controlar inventario con decremento automático.
  • Garantizar trazabilidad de ventas y auditoría.
  • Facilitar reportes y exportación de datos.
2. Requisitos técnicos y operativos

Clientes finales

  • Navegador moderno (Chrome, Edge, Safari, Firefox) o PWA instalable.
  • Conexión a internet o red local del establecimiento.
  • QR impreso o en pantalla.

Administradores / operadores

  • Node.js 18+ y PostgreSQL 14+ (o Docker Compose).
  • Variables de entorno configuradas (.env): DATABASE_URL, SESSION secret, CORS origin.
  • Impresora térmica 58/80mm (opcional).
  • HTTPS en producción.
3. Acceso y autenticación
  1. Abrir la URL del sistema.
  2. Ingresar credenciales de staff (admin, bartender, cajero) o PIN.
  3. Seleccionar establecimiento si aplica.

Seguridad: rate limiting en login, bloqueo por intentos fallidos, expiración de sesiones configurable, 2FA para admin (opcional).

4. Gestión de clientes
  • Registro: nombre, documento, teléfono → genera QR único.
  • Consulta de saldo de cervezas e historial de compras.
  • Recarga de saldo (compra) y canje (redención).
  • Crédito/fiado: límite configurable, lista de morosos, notificaciones.
  • Lealtad: puntos por compra, niveles bronce/plata/oro con descuentos.
5. Ventas y pedidos
  • Venta rápida por QR o búsqueda de cliente.
  • Combo purchase con pago (efectivo/transferencia).
  • Pedidos de clientes con estados.
  • Impresión de ticket térmico (58/80mm) con auto-impresión opcional.
6. Inventario
  • Registro de stock (cajas/botellas).
  • Auto-decremento al vender.
  • Alertas de stock bajo (umbral configurable).
  • Historial de entradas/salidas.
7. Caja (Z-report)
  • Apertura y cierre de turno.
  • Comparación esperado vs contado, diferencia.
  • Historial de cierres diarios.
8. Reportes y exportación
  • Ventas por día/hora, top clientes, desglose diario.
  • Filtros por fecha, bartender, tipo, cliente.
  • Exportación a CSV, Excel (.xlsx) y PDF.
  • Auditoría de acciones (usuario, acción, entidad, fecha, IP).
9. Administración y plataforma
  • Gestión de staff: roles, PIN, bloqueo por intentos.
  • Configuración de establecimiento: precio, tema, logo.
  • Plataforma (super-admin): onboarding, suscripciones, backup JSON.
10. PWA, offline y UX
  • Instalación como app (Agregar a pantalla de inicio).
  • Service worker cachea assets; funciona offline parcialmente.
  • Modo oscuro/claro, impresión térmica, teclado numérico.
11. Seguridad
  • Rate limiting en login, redeem y fast-sale.
  • Sesiones con expiración configurable.
  • Auditoría de acciones con IP.
  • Backup automático recomendado.
12. Despliegue y operaciones
  • Docker Compose con PostgreSQL y Redis.
  • HTTPS con certificado SSL.
  • Endpoint /api/health para monitoreo.
  • Backup automático (export JSON diario).
13. Soporte y resolución de problemas
  • Revisar logs del backend y /api/health.
  • Verificar conectividad DB.
  • Limpiar caché del navegador si hay problemas de carga.
  • Contactar administrador de plataforma para incidencias.
